# -New-Banking-Management-System


A simple banking application developed using Java.

Features

- Account details
- Deposit money
- Withdraw money
- Check balance
- Transaction history

Technologies Used

- Java
- Object-Oriented Programming

Concepts Used

- Classes and Objects
- Encapsulation
- Methods
- Loops
- Conditional Statements

How to Run

1. Download BankingManagement.java.
2. Compile and run the Java program.
3. Follow the banking menu.
